## 📋 Sobre o Projeto

Sistema web desenvolvido para a **DEIC (Divisão Especializada de Investigações Criminais)** do servidor Brasil Roleplay. A plataforma oferece gerenciamento completo de investigações criminais, registro de ocorrências, consulta ao código penal e administração de equipes.

### ✨ Funcionalidades Principais

- 🔐 **Sistema de Autenticação** - Login seguro com Supabase
- 📊 **Dashboard Administrativo** - Painel completo para gestão
- 📝 **Registro de Ocorrências** - Cadastro detalhado de casos
- ⚖️ **Código Penal** - Consulta rápida à legislação
- 👥 **Gerenciamento de Equipes** - Controle de investigadores
- 📱 **PWA (Progressive Web App)** - Instalável em dispositivos móveis
- 🎨 **Interface Moderna** - Design profissional e responsivo

## 📦 Instalação e Execução

### Pré-requisitos

- Node.js (versão 18 ou superior)
- npm ou yarn
- Conta no Supabase (para banco de dados)

### Passo a Passo

1. **Clone o repositório**
   ```bash
   git clone https://github.com/MatheusDev-sys/DEIC.git
   cd DEIC
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Configure as variáveis de ambiente**
   
   Crie um arquivo `.env.local` na raiz do projeto:
   ```env
   GEMINI_API_KEY=sua_chave_api_aqui
   ```

4. **Execute o projeto**
   ```bash
   npm run dev
   ```

5. **Acesse no navegador**
   ```
   http://localhost:3000
   ```

### Build para Produção

```bash
npm run build
npm run preview
```

## 📱 PWA - Progressive Web App

O sistema pode ser instalado como aplicativo em dispositivos móveis e desktop:

1. Acesse o site pelo navegador
2. Clique em "Adicionar à tela inicial" (mobile) ou no ícone de instalação (desktop)
3. O app será instalado e poderá ser usado offline
